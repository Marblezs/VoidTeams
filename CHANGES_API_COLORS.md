# Cambios

- API pública `me.VoidTeams.api.VoidTeamsAPI`.
- Registro mediante Bukkit `ServicesManager`.
- Provider estático `VoidTeamsProvider`.
- Modelos públicos `TeamScenarioInfo` y `TeamInfo`.
- Evento público `TeamScenarioStateChangeEvent`.
- Activar, desactivar y alternar Team Scenarios desde plugins externos.
- Lectura pública de TeamSize, tipo, Friendly Fire, locks, equipos, miembros, colores e iconos.
- Integración preparada para representar Team Scenarios como scenarios normales dentro de VoidUHC.
- 36 colores RGB configurados y 31 aliases de color.
- Tab completion de colores ampliado.
- Comentarios eliminados del source Java.
