# VoidTeams 2.2.2

- Nuevo `/teamadm` GUI para hosters.
- Selector visual de TeamSize y tipo base.
- Configuración visual de Captains y Auction.
- Captains y Auction excluyen hosters y spectators por defecto durante la formación; puede cambiarse desde el GUI.
- Placeholders de modo compactos: FFA, Cto2, Rto2, VtoN, Captains, Auction y soporte futuro para LAFS.
- API pública ampliada con `getEffectiveTeamType()` y `getTeamSizeDisplay()`.
- Nombres de jugadores sin BOLD en Team Chat e invitaciones.
- Auction permite configurar créditos, tiempo, puja inicial, incremento mínimo y anti-snipe desde GUI.
